# Vision OS by Akko

Browser desktop OS with Rias Gremory & Marin Kitagawa themes.

## Live

After enabling GitHub Pages:

**https://baobao739.github.io/vision-os/**

## Setup images

Put these files in the `assets/` folder:

- `assets/rias.jpg` — Rias Gremory
- `assets/marin.jpg` — Marin Kitagawa

Then the desktop pet will show the real characters.

## Enable GitHub Pages

1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / root
4. Save

## Features

- Real window manager (drag, resize, snap, maximize)
- Two themes: Rias / Marin
- Desktop pet (click her)
- Files, Browser (proxy), Notes, Calculator, Music, Calendar, Terminal, Settings
- localStorage persistence
